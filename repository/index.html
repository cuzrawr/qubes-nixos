NixOS templates for Qubes 4.3

x86_64, XFCE/Xorg, stock Qubes PVH kernel. Stable NixOS 26.05 and a pinned development snapshot for 26.11.

  1. Set up the repository once.
  2. Open Qubes Template Manager, refresh, and install nixos-26.05-xfce or nixos-unstable-xfce.
  3. Create an AppVM using that template.
